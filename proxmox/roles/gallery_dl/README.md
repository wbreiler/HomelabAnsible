# Retired Gallery role

The user confirmed that Gallery is no longer live on 2026-10-24.
This directory remains as reference code. `site.yml` does not import it, and
active local variables and the tracked example no longer enable or configure it.
The old `gallery_dl` tag and `install_gallery_dl=true` flag cannot deploy it
through `site.yml`.

Do not reconnect this role to an active playbook without an explicit new
deployment request. Retirement does not delete data, backups, or the ignored
cookies file.
